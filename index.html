找不到此員工

請前往 Google AI Studio 專案與帳務管理 ↗， 確認目前 API 金鑰所屬專案的帳務帳戶與預付餘額。補足額度後再按「重新辨識」；若改用其他有可用額度的專案，請回上傳頁更換金鑰。同一個餘額耗盡的帳務帳戶下，更換金鑰仍無法恢復。
